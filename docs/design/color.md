# Color Architecture (Anaxly Universal Royal Scholastic Blue System)

**Last Updated:** October 2026
**Theme Source of Truth:** `src/config/theme.ts`
**Theme Preset:** Royal Scholastic Blue (Zero Orange)

This document specifies the authoritative color tokens and variable names governing all surfaces, typography inks, interactive states, and chalkboard chalks across Anaxly.

---

## 1. Environment & Paper Canvas
*   **Canvas Base (`--canvas-base`):** `#FAF8F4` — Warm Tuscan Vellum Parchment (distinct from Aristotle's `#F8F6F0`).
*   **Surface White (`--canvas-surface`):** `#FFFFFF` — Crisp, elevated interactive containers and cards.
*   **Canvas Soft (`--canvas-soft`):** `#F4F1EA` — Secondary cards, badge backings, and pill containers.
*   **Paper Border Subtle (`--border-subtle`):** `#E2E6EA` — Delicate cool-tinted hairline dividers.
*   **Paper Border Strong (`--border-strong`):** `#CBD5E1` — Active borders, card boundaries, and input focus outlines.

## 2. Typography & Ink Hierarchy (Deep Slate Blue-Tinted Inks)
*   **Primary Ink (`--ink-primary`):** `#0F172A` — Deep Royal Obsidian Slate (rich scholastic navy-tinted charcoal, matches login/onboarding).
*   **Secondary Ink (`--ink-secondary`):** `#334155` — Subtitles, instructional text, form labels, metadata.
*   **Muted Ink (`--ink-muted`):** `#64748B` — Placeholders, secondary labels, timer countdowns.
*   **Hairline Ink (`--ink-hairline`):** `#94A3B8` — Copyright notes, micro-captions, subtle dividers.
